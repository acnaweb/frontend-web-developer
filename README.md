# Frontend Web Developer Roadmap — 8 Meses

Roadmap estruturado para formação em **Frontend Web Development**, conectando de forma progressiva os conhecimentos de **Web Design**, **UX/UI**, **Figma**, **Design System**, **HTML**, **CSS**, **JavaScript**, **Git/GitHub**, **React**, **APIs**, **Testes**, **Arquitetura Frontend**, **CI/CD** e **Deploy**.

## Objetivo

A proposta deste repositório é separar claramente os conceitos de:

- **Web Design** — foco em experiência, interface, prototipação e consistência visual;
- **Web Development** — foco em implementação, comportamento, integração e engenharia;
- **Frontend Engineering** — foco em arquitetura, qualidade, performance, segurança e entrega.

Ao mesmo tempo, o roadmap mostra como essas áreas se conectam.
