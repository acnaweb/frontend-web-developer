# Semana 01 — Como a Web funciona

## Objetivo

Estudar e praticar os fundamentos relacionados a **Como a Web funciona**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Internet x Web;
- Cliente x Servidor;
- Browser;
- HTTP e HTTPS;
- URL e DNS;
- Request e Response;
- Status HTTP;
- HTML, CSS e JavaScript;
- DOM;
- JSON;
- APIs;

## Laboratório

Utilizar o Chrome DevTools para analisar requisições HTTP, headers, payloads, responses, HTML, CSS e DOM.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
