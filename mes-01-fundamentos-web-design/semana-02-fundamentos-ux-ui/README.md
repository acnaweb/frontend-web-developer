# Semana 02 — Fundamentos de UX/UI

## Objetivo

Estudar e praticar os fundamentos relacionados a **Fundamentos de UX/UI**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- User Experience;
- Jornada do usuário;
- User Flow;
- Arquitetura da informação;
- Wireframes;
- Usabilidade;
- Hierarquia visual;
- Layout;
- Grid;
- Cores;
- Tipografia;
- Espaçamento;
- Contraste;

## Laboratório

Criar o wireframe de uma aplicação Web simples.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
