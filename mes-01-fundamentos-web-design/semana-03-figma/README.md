# Semana 03 — Figma

## Objetivo

Estudar e praticar os fundamentos relacionados a **Figma**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Frames;
- Layers;
- Groups;
- Components;
- Instances;
- Variants;
- Styles;
- Grid;
- Auto Layout;
- Constraints;
- Alignment;
- Spacing;

## Laboratório

Criar no Figma um conjunto inicial de componentes: Header, Navbar, Button, Input, Card, Modal e Formulário.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.

Continue para a próxima semana do roadmap.
