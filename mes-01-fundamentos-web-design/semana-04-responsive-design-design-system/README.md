# Semana 04 — Responsive Design e Design System

## Objetivo

Estudar e praticar os fundamentos relacionados a **Responsive Design e Design System**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Mobile;
- Tablet;
- Desktop;
- Breakpoints;
- Mobile First;
- Fluid Layout;
- Foundations;
- Tokens;
- Components;
- Patterns;
- Guidelines;

## Laboratório

Criar a primeira versão de um Design System no Figma.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
