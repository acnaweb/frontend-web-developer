# Semana 05 — HTML

## Objetivo

Estudar e praticar os fundamentos relacionados a **HTML**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Tags;
- Elements;
- Attributes;
- Estrutura do documento;
- HTML Semântico;
- Formulários;
- Labels;
- Inputs;
- Buttons;
- Validação básica;

## Laboratório

Transformar uma tela criada no Figma em HTML semântico.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
