# Semana 06 — CSS

## Objetivo

Estudar e praticar os fundamentos relacionados a **CSS**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Selectors;
- Cascade;
- Specificity;
- Inheritance;
- Box Model;
- Display;
- Position;
- Flexbox;
- CSS Grid;

## Laboratório

Estilizar a página HTML criada na semana anterior.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
