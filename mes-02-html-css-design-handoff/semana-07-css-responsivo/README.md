# Semana 07 — CSS Responsivo

## Objetivo

Estudar e praticar os fundamentos relacionados a **CSS Responsivo**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Media Queries;
- Breakpoints;
- Mobile First;
- Unidades relativas;
- px;
- %;
- em;
- rem;
- vw;
- vh;

## Laboratório

Transformar a aplicação em uma interface responsiva para Mobile, Tablet e Desktop.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
