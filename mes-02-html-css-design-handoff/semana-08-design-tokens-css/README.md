# Semana 08 — Design Tokens no CSS

## Objetivo

Estudar e praticar os fundamentos relacionados a **Design Tokens no CSS**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Design Tokens;
- CSS Variables;
- Cores;
- Spacing;
- Radius;
- Tipografia;
- Integração Figma → CSS;

## Laboratório

Converter tokens definidos no Figma para variáveis CSS e aplicá-los nos componentes.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
