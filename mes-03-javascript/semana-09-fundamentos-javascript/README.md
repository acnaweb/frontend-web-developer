# Semana 09 — Fundamentos de JavaScript

## Objetivo

Estudar e praticar os fundamentos relacionados a **Fundamentos de JavaScript**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Variables;
- Data Types;
- Operators;
- Conditionals;
- Loops;
- Functions;
- Scope;
- Arrays;
- Objects;
- Map;
- Set;

## Laboratório

Criar pequenos exercícios de lógica e manipulação de dados com JavaScript.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
