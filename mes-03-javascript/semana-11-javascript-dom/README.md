# Semana 11 — JavaScript e DOM

## Objetivo

Estudar e praticar os fundamentos relacionados a **JavaScript e DOM**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- DOM;
- querySelector;
- querySelectorAll;
- Events;
- Event Listeners;
- Event Bubbling;
- Manipulação de elementos;
- Form Validation;

## Laboratório

Criar uma aplicação com formulário, validação, inclusão, exclusão e atualização dinâmica da interface.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
