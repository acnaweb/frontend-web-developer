# Semana 12 — JavaScript Assíncrono

## Objetivo

Estudar e praticar os fundamentos relacionados a **JavaScript Assíncrono**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Callbacks;
- Promises;
- async;
- await;
- fetch;
- REST;
- JSON;
- Tratamento de erros;

## Laboratório

Criar uma aplicação JavaScript que consuma uma API REST pública.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
