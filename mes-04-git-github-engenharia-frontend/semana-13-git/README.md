# Semana 13 — Git

## Objetivo

Estudar e praticar os fundamentos relacionados a **Git**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Repository;
- Commit;
- Branch;
- Merge;
- Conflict;
- Tag;
- .gitignore;
- Staging Area;

## Laboratório

Criar um repositório Git local e praticar commits, branches, merges e resolução de conflitos.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
