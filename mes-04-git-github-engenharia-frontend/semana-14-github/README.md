# Semana 14 — GitHub

## Objetivo

Estudar e praticar os fundamentos relacionados a **GitHub**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Repository;
- Branch;
- Pull Request;
- Issues;
- Releases;
- Discussions;
- Feature Branch;
- Code Review;

## Laboratório

Publicar o projeto no GitHub e simular um fluxo com branch, Pull Request e Code Review.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
