# Semana 17 — Fundamentos de React

## Objetivo

Estudar e praticar os fundamentos relacionados a **Fundamentos de React**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- SPA;
- JSX;
- Components;
- Props;
- State;
- Events;
- Conditional Rendering;
- Lists;
- Keys;

## Laboratório

Criar uma aplicação React simples baseada em componentes.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
