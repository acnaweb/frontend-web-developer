# Semana 18 — React Hooks

## Objetivo

Estudar e praticar os fundamentos relacionados a **React Hooks**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- useState;
- useEffect;
- useRef;
- Custom Hooks;
- useMemo;
- useCallback;

## Laboratório

Criar componentes com estado, efeitos e pelo menos um Custom Hook.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
