# Semana 19 — Componentização

## Objetivo

Estudar e praticar os fundamentos relacionados a **Componentização**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Componentes reutilizáveis;
- Props;
- Variants;
- States;
- Design Tokens;
- Componentes de UI;
- Separação de responsabilidades;

## Laboratório

Transformar elementos do Design System do Figma em componentes React reutilizáveis.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
