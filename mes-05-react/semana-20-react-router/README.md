# Semana 20 — React Router

## Objetivo

Estudar e praticar os fundamentos relacionados a **React Router**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- SPA Routing;
- Routes;
- Nested Routes;
- URL Params;
- Query Params;
- Layouts;

## Laboratório

Criar uma aplicação React com múltiplas rotas e navegação.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
