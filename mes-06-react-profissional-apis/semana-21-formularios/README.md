# Semana 21 — Formulários

## Objetivo

Estudar e praticar os fundamentos relacionados a **Formulários**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Controlled Components;
- Form State;
- Validation;
- Error Messages;
- React Hook Form;
- Zod;

## Laboratório

Criar um formulário completo com validação e mensagens de erro.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
