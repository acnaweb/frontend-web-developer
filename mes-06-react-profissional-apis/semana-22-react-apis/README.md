# Semana 22 — React + APIs

## Objetivo

Estudar e praticar os fundamentos relacionados a **React + APIs**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- GET;
- POST;
- PUT;
- PATCH;
- DELETE;
- Loading;
- Error;
- Empty State;
- Success State;

## Laboratório

Integrar a aplicação React com uma API REST e implementar estados de carregamento, erro e vazio.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
