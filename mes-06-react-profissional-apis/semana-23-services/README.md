# Semana 23 — Services

## Objetivo

Estudar e praticar os fundamentos relacionados a **Services**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Separação UI/API;
- Services;
- HTTP Client;
- Tratamento de erros;
- Organização de integrações;

## Laboratório

Mover o acesso à API para uma camada de services separada dos componentes.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
