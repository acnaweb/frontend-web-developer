# Semana 24 — Gerenciamento de Estado

## Objetivo

Estudar e praticar os fundamentos relacionados a **Gerenciamento de Estado**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Local State;
- Lift State Up;
- Context API;
- Global State;
- Zustand;
- Redux — introdução;

## Laboratório

Criar um CRUD React com estado compartilhado e integração com API.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
