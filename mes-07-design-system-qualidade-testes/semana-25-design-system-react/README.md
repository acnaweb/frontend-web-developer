# Semana 25 — Design System em React

## Objetivo

Estudar e praticar os fundamentos relacionados a **Design System em React**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Foundations;
- Tokens;
- Components;
- Patterns;
- Documentation;
- Button;
- Input;
- Select;
- Card;
- Modal;
- Tabs;
- Table;
- Toast;

## Laboratório

Criar a primeira versão de um Design System em React.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
