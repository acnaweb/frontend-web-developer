# Semana 26 — Estados dos Componentes

## Objetivo

Estudar e praticar os fundamentos relacionados a **Estados dos Componentes**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Default;
- Hover;
- Focus;
- Active;
- Disabled;
- Loading;
- Error;
- Accessibility;

## Laboratório

Implementar variantes e estados visuais e comportamentais dos componentes do Design System.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
