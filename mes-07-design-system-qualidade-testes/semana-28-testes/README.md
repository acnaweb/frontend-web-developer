# Semana 28 — Testes

## Objetivo

Estudar e praticar os fundamentos relacionados a **Testes**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Unit Tests;
- Integration Tests;
- E2E;
- Vitest;
- React Testing Library;
- Playwright;

## Laboratório

Criar testes unitários, de integração e ao menos um fluxo E2E.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
