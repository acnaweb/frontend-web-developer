# Semana 29 — Arquitetura Frontend

## Objetivo

Estudar e praticar os fundamentos relacionados a **Arquitetura Frontend**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Separation of Concerns;
- Component Architecture;
- Feature-based Architecture;
- Services;
- Hooks;
- State Management;
- shared;
- features;

## Laboratório

Reorganizar uma aplicação React utilizando arquitetura orientada a features.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
