# Semana 30 — Performance

## Objetivo

Estudar e praticar os fundamentos relacionados a **Performance**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- Bundle Size;
- Lazy Loading;
- Code Splitting;
- Image Optimization;
- Browser Cache;
- CDN;
- Core Web Vitals;
- LCP;
- CLS;
- INP;
- Lighthouse;

## Laboratório

Medir e melhorar a performance da aplicação utilizando Chrome DevTools e Lighthouse.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
