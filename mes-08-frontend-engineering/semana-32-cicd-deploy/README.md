# Semana 32 — CI/CD e Deploy

## Objetivo

Estudar e praticar os fundamentos relacionados a **CI/CD e Deploy**, conectando o conteúdo ao desenvolvimento progressivo da carreira de Frontend Web Developer.

## Tópicos

- GitHub Actions;
- Lint;
- Tests;
- Build;
- Deploy;
- GitHub Pages;
- Vercel;
- Netlify;
- Firebase Hosting;
- Cloud Storage;
- CDN;
- Cloud Run;

## Laboratório

Criar um pipeline GitHub Actions para lint, testes, build e deploy da aplicação.

## Resultado esperado

Ao final da semana, o aluno deverá:

- compreender os conceitos principais;
- aplicar os conhecimentos em um exercício prático;
- registrar a evolução no GitHub;
- relacionar o conteúdo com as etapas anteriores do roadmap.
