# Projeto Integrador

O projeto integrador consolida os conhecimentos desenvolvidos ao longo das 32 semanas.

## Fluxo

```text
Problema
   │
   ▼
UX
   │
   ▼
Wireframe
   │
   ▼
Figma
   │
   ▼
Design System
   │
   ▼
Prototype
   │
   ▼
GitHub
   │
   ▼
HTML / CSS
   │
   ▼
React
   │
   ▼
API
   │
   ▼
Tests
   │
   ▼
CI/CD
   │
   ▼
Deploy
```

## Requisitos

- Protótipo no Figma;
- Design System básico;
- Design Tokens;
- Layout responsivo;
- Repositório GitHub;
- README;
- React;
- Componentização;
- Integração com API;
- Formulários;
- Tratamento de erros;
- Loading State;
- Empty State;
- Testes;
- CI/CD;
- Deploy público.

## Objetivo

Demonstrar não apenas capacidade de criar telas, mas domínio do fluxo completo entre Design, Desenvolvimento, Qualidade e Entrega.
